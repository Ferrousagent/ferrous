## Adding an ADR

1. Copy the newest numbered ADR.
2. Name it `NNNN-<kebab-case>.md` with the next number.
3. Fill `Status` (`Proposed` / `Accepted` / `Superseded`), `Context`, `Decision`, `Consequences`.
4. Add a row to the index above.
